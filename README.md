# Express Routing API

## 📌 Project Description

This project is a simple REST API developed using **Node.js** and **Express.js**. It demonstrates how to organize routes using Express Router.

---

## 🚀 Features

- User Routes
- Product Routes
- Express Router
- JSON API Responses
- Modular Folder Structure

---

## 🛠 Technologies Used

- Node.js
- Express.js
- JavaScript

---

## 📂 Project Structure

```text
exp2/
```

---

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/garikapatiramyasri555-arch/exp2.git
```

Go to the project folder:

```bash
cd exp2
```

Install the required packages:

```bash
npm install
```

---

## ▶️ Run the Project

```bash
node Server.js
```
